Privacy By Design

Built with strict Local-First integrity

Most browser extensions silently track your browsing history or call remote APIs. Cinedrape was engineered from line 1 with zero network calls and strict sandboxing.

Security & Privacy Vector Cinedrape Standard Browser Extensions
Telemetry & Analytics ✓ Zero (0 network requests in content script) ✗ Google Analytics, Mixpanel, Sentry telemetry
Account Requirement ✓ None (Runs 100% on-device) ✗ Mandatory cloud account & email logins
Ad & Player Safety ✓ Strict Validator (Cannot hide ads or player) ✗ Unchecked CSS often breaks player & monetisation
Failure Handling ✓ Fail-Open (Reverts to standard YouTube on error) ✗ Leaves broken layouts and unplayable video pages
Executable Code Storage ✓ Pure JSON Data (0 eval, 0 new Function) ✗ Remote code scripts, eval(), unvetted injections
DOM Compatibility Updates ✓ ECDSA Signed Map (Cryptographically verified) ✗ Unsigned hardcoded scraper selectors
Get Started

Install in under 60 seconds

Try Cinedrape today on Chrome, Microsoft Edge, Brave, or Firefox. 100% free — all 16 themes, layouts, and calm mode filters included.

  1. 1

    Download or Build the Extension

    Download the latest release archive from GitHub, or clone and build locally:

    git clone https://github.com/JDamour/Cinedrape.git && cd Cinedrape && npm install && npm run build
  2. 2

    Open Extensions in Your Browser

    Navigate to chrome://extensions in Chrome/Brave or edge://extensions in Microsoft Edge. Switch on the Developer mode toggle.

  3. 3

    Load Unpacked

    Click Load unpacked and select the dist/ folder (or dist-edge/ for Edge). Navigate to youtube.com and click the Cinedrape icon in your toolbar!

  1. 1

    Build for Firefox

    Cinedrape includes dedicated Firefox Manifest V3 target builds:

    npm run build:firefox
  2. 2

    Open Firefox Debugging

    In Firefox, enter about:debugging#/runtime/this-firefox into the address bar.

  3. 3

    Load Temporary Add-on

    Click Load Temporary Add-on... and select dist-firefox/manifest.json.

  1. 1

    Clone & Build Strictly

    npm install && npm run build:strict
  2. 2

    Run Test Suite (2062 automated checks)

    npm test
  3. 3

    Package Multi-Browser Release Archives (Chrome, Edge & Firefox)

    Build and package clean store-ready archives into release/:

    npm run package:dev

No. Cinedrape applies styles via high-performance CSS custom properties (variables) injected once into the page root. We avoid heavy JavaScript mutation loops. In fact, Calm Mode often speeds up page responsiveness by hiding dynamic comment threads and endless recommendations.

Cinedrape uses a dual protection model: First, all selectors are separated into an ECDSA-signed selector map. Second, our fail-open health monitor continuously checks whether expected elements are present. If YouTube introduces an incompatible DOM change, Cinedrape gracefully turns off only the affected layout component and keeps the rest of YouTube functioning normally.
